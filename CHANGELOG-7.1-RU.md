# Blackgram 7.1 — Telegram-style UX

Основано на 7.0. Firebase, звонки, Mega Center и админка сохранены.

## Интерфейс
- **Свайп по чату в списке:** вправо — закрепить/открепить; влево — «Без звука» и «В архив» (возврат из архива там же).
- **«Печатает…» и «в сети»** в списке чатов: зелёная точка на аватаре, подпись «печатает…» вместо превью.
- **Кнопка «вниз»** в переписке со счётчиком новых сообщений (появляется, если ты прокрутил вверх).
- **Закреплённое сообщение** сверху чата (меню сообщения → «📌 Закрепить»; тап по плашке — переход к сообщению; ✕ — открепить).
- **Свайп по сообщению влево** — ответить.
- **Разделители дат:** «Сегодня», «Вчера», «12 ноября».
- **Экран звонка как в Telegram:** размытый аватар на фоне, большие круглые кнопки (микрофон, камера, завершить; принять/отклонить), таймер разговора.

## Приватность
- Вкладка «Люди» теперь показывает только **контакты** и тех, с кем уже есть личный чат. Новые зарегистрированные пользователи **сами не появляются**.
- Найти человека: ввести его `@username` или e-mail **целиком** во вкладке «Люди» → он появится в результатах; открытие чата или «Добавить в контакты» в профиле сохраняет его в контакты (синхронизируются через Firestore: `users/{uid}/bg6/contacts`).
- Группы создаются из списка контактов.

## Деплой
```bash
firebase deploy --only firestore:rules,functions
```
- rules: участники чата могут менять `pinnedMsg` (общий закреп). Без деплоя закреп работает только локально у того, кто закрепил.
- functions: push не отправляется в чаты, помеченные «Без звука» (`users/{uid}.mutedChats`).
- Кэш сервис-воркера: `blackgram-shell-v710`.

## Ограничения
- Правила Firestore по-прежнему разрешают авторизованному клиенту читать `users` (это нужно приложению для имён/аватаров в чатах). Список скрыт в интерфейсе, но не закрыт на уровне правил.
- Контакты нельзя удалять (пока).
- Не проверено в этой среде: реальный вход Firebase, жесты на устройстве, звонки. Проверено: синтаксис модуля, одинаковость index.html в трёх каталогах, тесты `node --test tests/*.js`.

## 7.1.1 — пометка «18+» для фото
- Кнопка 🔞 рядом с «📷 Фото»: включи её, и **следующее** фото уйдёт с пометкой 18+ (после отправки кнопка выключается).
- Получатель видит такое фото размытым с надписью «Фото 18+ — нажми, чтобы показать»; открытое остаётся открытым, пока чат не перезагружен. Автор своё фото видит без размытия.
- Поле `sensitive: true` в документе сообщения; правила Firestore менять не нужно.
- Ограничение: пометка ставится отправителем вручную, автоматического распознавания содержимого нет.

## 7.1.3 — группы и каналы
- В группу и канал можно добавлять участников (кнопка ℹ в шапке чата, только создатель). Раньше подписчиков в канал добавить было нельзя.
- Участник может выйти из группы или канала.
- В канал пишет только создатель; у подписчиков поле ввода отключено. Ограничение действует и в `firestore.rules`.
- Опубликуй обновлённый `firestore.rules`, иначе выход из группы и запрет записи в канал на сервере работать не будут.
- Нижняя навигация: подсвечена одна вкладка, по умолчанию «Чаты». Версия в заголовке страницы — 7.1.

## 7.1.4 — деплой Storage
- В `firebase.json` добавлен раздел `storage`, теперь `storage.rules` уходит в деплой.
- Команда деплоя: `firebase deploy --only firestore:rules,storage,functions`.

## 7.1.4 — закрытие users, manageGroups
- **`users` закрыт:** e-mail и push-токены читают только сам пользователь, владелец и админ с `viewUsers`. Остальным приложение отдаёт `publicProfiles/{uid}` (имя, @username, аватар, галочка, теги, присутствие). Копию ведёт Cloud Function `syncPublicProfile`.
- **Поиск по e-mail** работает по SHA-256 хэшу: точный адрес находит человека, список адресов получить нельзя.
- **manageGroups работает:** в панели админа кнопка «Группы и каналы» (переименовать, удалить). В правилах такой админ меняет только `title` и `about` и удаляет чат, переписку не читает. `cleanupDeletedChat` удаляет сообщения вместе с чатом.
- Кэш сервис-воркера: `blackgram-shell-v714`.

### Порядок деплоя (важен)
1. `firebase deploy --only functions`
2. Войди владельцем: при первом входе приложение само вызовет `backfillPublicProfiles` (иначе люди появятся в списке только после своего следующего входа).
3. `firebase deploy --only firestore:rules,storage,hosting`

Если опубликовать правила раньше шага 2, список людей будет пустым, пока профили не заполнятся.

### Что остаётся за пределами кода
- Вставить VAPID-ключ из Firebase Console вместо `PASTE_FIREBASE_WEB_PUSH_CERTIFICATE_KEY_HERE`.
- Cloud Functions (в том числе отложенные сообщения) работают только после деплоя.

## 7.2 — градиентный скин в стиле Telegram
- Шапка и кнопки с сине-фиолетовым градиентом (#2AABEE → #5B6CF0 → #8B5CF6), свои сообщения и кнопка отправки тоже в градиенте.
- Аватары с разными градиентами, размытые шапка чата и нижняя панель, мягкое свечение на фоне переписки, градиентные вкладки и фильтры.
- Только CSS, логика не менялась. Скин действует в стандартной теме; темы forest, purple и light остаются прежними.
- Кэш сервис-воркера: `blackgram-shell-v720`.

## 7.3 — оболочка как в Telegram
- **Боковое меню (☰ или свайп от левого края):** профиль, создать группу и канал, избранное, каталог, стикеры, архив, username, приватность, чёрный список, оформление, поддержка, админка (только если есть доступ), выход. Все пункты вызывают уже существующие кнопки.
- **Шапка:** ☰, название, 🔍. Поиск скрыт и открывается по 🔍, по вкладкам «Люди» и «Поиск» и по Ctrl+K.
- **Папки чатов** прокручиваются по горизонтали.
- **Поле ввода:** 📎 открывает панель вложений (фото, голос, звонок, видео, реакции, канал), 😊 открывает панель эмодзи, 🎙 превращается в ➤, когда есть текст.
- **Шапка чата:** круглый аватар собеседника. Цвет аватара постоянный для каждого человека.
- Фон переписки с тонким узором, волна-ripple на кнопках, лёгкая вибрация на телефоне, Esc закрывает меню и панели.
- Только интерфейс, логика Firebase не менялась. Кэш: `blackgram-shell-v730`.

## 7.5 — Aurora (премиальный слой)
- Графитовая палитра, стеклянные шапка, папки, поле ввода и нижняя панель (blur), тонкая градиентная линия под шапкой.
- Градиентные акценты (#4F8CFF → #7C5CFF → #C05CFF): свои сообщения, кнопка отправки, кнопка нового чата, вкладки, значки непрочитанного, логотип и надпись на экране входа.
- Анимации: плавное появление строк чатов и пузырей, всплытие окон, нажатие кнопок, плавающий логотип на входе. Для `prefers-reduced-motion` анимации отключаются.
- Скелетон загрузки списка чатов и пустое состояние («Пока нет чатов») через 4,5 с без чатов.
- Узкие экраны: `overflow-x:hidden`, перенос длинных слов, сжатые аватары и панель вложений на ширине до 360 px.
- Исправлены: пропадавшая иконка активной вкладки, двойные разделители в списке, тёмный квадрат за кнопками шапки чата, сплошной прямоугольник вместо градиентной надписи.
- Кэш: `blackgram-shell-v750`.
