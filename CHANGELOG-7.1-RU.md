# Blackgram 7.1 — Telegram-style UX

Основано на 7.0. Firebase, звонки, Mega Center и админка сохранены.

## Интерфейс
- **Свайп по чату в списке:** вправо — закрепить/открепить; влево — «Без звука» и «В архив» (возврат из архива там же).
- **«Печатает…» и «в сети»** в списке чатов: зелёная точка на аватаре, подпись «печатает…» вместо превью.
- **Кнопка «вниз»** в переписке со счётчиком новых сообщений (появляется, если ты прокрутил вверх).
- **Закреплённое сообщение** сверху чата (меню сообщения → «📌 Закрепить»; тап по плашке — переход к сообщению; ✕ — открепить).
- **Свайп по сообщению влево** — ответить.
- **Разделители дат:** «Сегодня», «Вчера», «12 ноября».
- **Экран звонка как в Telegram:** размытый аватар на фоне, большие круглые кнопки (микрофон, камера, завершить; принять/отклонить), таймер разговора.

## Приватность
- Вкладка «Люди» теперь показывает только **контакты** и тех, с кем уже есть личный чат. Новые зарегистрированные пользователи **сами не появляются**.
- Найти человека: ввести его `@username` или e-mail **целиком** во вкладке «Люди» → он появится в результатах; открытие чата или «Добавить в контакты» в профиле сохраняет его в контакты (синхронизируются через Firestore: `users/{uid}/bg6/contacts`).
- Группы создаются из списка контактов.

## Деплой
```bash
firebase deploy --only firestore:rules,functions
```
- rules: участники чата могут менять `pinnedMsg` (общий закреп). Без деплоя закреп работает только локально у того, кто закрепил.
- functions: push не отправляется в чаты, помеченные «Без звука» (`users/{uid}.mutedChats`).
- Кэш сервис-воркера: `blackgram-shell-v710`.

## Ограничения
- Правила Firestore по-прежнему разрешают авторизованному клиенту читать `users` (это нужно приложению для имён/аватаров в чатах). Список скрыт в интерфейсе, но не закрыт на уровне правил.
- Контакты нельзя удалять (пока).
- Не проверено в этой среде: реальный вход Firebase, жесты на устройстве, звонки. Проверено: синтаксис модуля, одинаковость index.html в трёх каталогах, тесты `node --test tests/*.js`.
