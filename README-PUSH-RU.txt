BLACKGRAM 5.3 — PUSH-УВЕДОМЛЕНИЯ

В проект добавлена отправка push-уведомлений о новых сообщениях через Firebase Cloud Messaging (FCM). Функция отправляет уведомление всем участникам чата, кроме отправителя. Текст уведомления ограничен 180 символами.

ОБЯЗАТЕЛЬНАЯ НАСТРОЙКА ОДИН РАЗ
1. Открой Firebase Console → проект blackgram-35ecf → Project settings → Cloud Messaging.
2. В разделе Web configuration создай/открой Web Push certificates и скопируй Key pair (VAPID public key).
3. В public/index.html найди BG5_VAPID_KEY и замени PASTE_FIREBASE_WEB_PUSH_CERTIFICATE_KEY_HERE на скопированный ключ. Не публикуй приватные ключи.
4. В Firebase Console включи Cloud Messaging API, если Firebase попросит. Для Cloud Functions обычно нужен тариф Blaze и активный биллинг.
5. Установи зависимости функций: cd functions && npm install
6. Из корня проекта выполни: firebase deploy --only functions:sendChatPush
7. Опубликуй сайт на HTTPS (например Firebase Hosting) и обнови приложение.
8. Войди в Blackgram на каждом устройстве и нажми «🔔 Уведомления», затем разреши уведомления браузеру/Android. На каждом устройстве нужно получить свой токен.

ПРОВЕРКА
Отправь сообщение с другого аккаунта. На устройстве получателя уведомление должно появиться и при закрытой вкладке/свернутом PWA, если ОС не ограничивает фоновые уведомления. В Android проверь системные разрешения уведомлений и отключи энергосбережение для приложения, если push задерживаются.

ВАЖНО
- Push не заработает до добавления VAPID-ключа и развёртывания Cloud Function. Эти действия требуют доступа владельца к Firebase Console.
- Firebase Cloud Messaging для Web требует HTTPS и поддерживаемого браузера.
- Сами сообщения и история чатов не передаются в эту функцию как публичный журнал; функция читает документ нового сообщения, чтобы сформировать уведомление.
- Уведомления могут показывать текст сообщения на экране блокировки. Учитывай это при использовании устройства.
- Чтобы отключить уведомления, запрети их в настройках браузера/Android. Токены можно удалить из users/{uid}.fcmTokens в Firestore.
