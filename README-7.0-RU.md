# Blackgram 7.0 — Telegram-style UI

Основано на 6.0. Логика, Firebase, чаты, звонки, Mega Center и админка сохранены.

## Что нового
- Новая тема в стиле Telegram: плоская палитра `#17212b`, список чатов с разделителями и аватарами 54px, вкладки-папки с подчёркиванием, пузыри с «хвостиками», тёмный фон переписки, круглая кнопка отправки, нижняя навигация.
- Плавающая кнопка «новая группа» в списке чатов.
- Теги пользователей: МОДЕРАТОР, VIP, БОТ, РАЗРАБОТЧИК, PRO, НОВИЧОК (до 3 у одного пользователя). Показываются рядом с именем вместе с ✓ и ролью.
- Control Center: кнопка «🏷 Теги» в карточке пользователя (владелец и админы с правом «галочки»), перекрашенные карточки статистики и пользователей.
- Светлая тема и цветные темы сохранены.

## Обязательно
```bash
firebase deploy --only firestore:rules,functions
```
Правила изменены: поле `tags` может менять только владелец или админ с правом `verifyUsers`; пользователь сам себе теги выдать не может.

## Не проверено в этой среде
Реальный вход Firebase, работа правил в Emulator, внешний вид на устройствах, Android/iOS сборка. Проверено: синтаксис модуля, одинаковость index.html в трёх каталогах, тесты `node --test tests/*.js`.
