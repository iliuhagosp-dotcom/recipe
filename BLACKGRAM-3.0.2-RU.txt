BLACKGRAM 3.0.2 — СТАТУСЫ И НАБОР СООБЩЕНИЯ

ДОБАВЛЕНО
- статус «в сети» в списке пользователей;
- примерное время последней активности, если пользователь не в сети;
- статус «печатает…» в шапке личного чата;
- обновление присутствия раз в 30 секунд, пока приложение активно;
- устаревшая сессия автоматически считается офлайн через 90 секунд без heartbeat;
- статус переключается при скрытии страницы и возвращении в приложение.

ВАЖНО
- Для работы нужен интернет и опубликованные текущие правила Firestore.
- Присутствие приблизительное: закрытие браузера/потеря сети может задержать смену статуса до 90 секунд.
- Статус набора сделан для личных чатов.
- Это не push-уведомления и не гарантирует работу в фоне на Android.

УСТАНОВКА
Загрузи содержимое recipe-main в ту же папку GitHub Pages, из которой публикуется Blackgram, затем Commit changes и дождись завершения публикации.
