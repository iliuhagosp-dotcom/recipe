ЗАМЕТКИ ПО ИСХОДНИКАМ TELEGRAM ANDROID

Загруженный репозиторий: Telegram-Android-master.zip
Основной Android-модуль: TMessagesProj
Лицензия в архиве: GNU GPL v2 or later (см. LICENSE)

README репозитория требует для собственного приложения:
- получить собственный api_id, если приложение подключается к Telegram API;
- не использовать название Telegram как имя собственного приложения;
- не использовать стандартный логотип Telegram;
- соблюдать рекомендации безопасности MTProto;
- публиковать собственный код для соблюдения лицензий.

Для Blackgram выбран самостоятельный Firebase backend. Поэтому Telegram API/MTProto и Telegram-аккаунты не используются. Код Telegram можно копировать/модифицировать только при соблюдении GPL-обязательств. Если требуется сохранить иной режим распространения Blackgram, предпочтительнее реализовывать необходимые Android-компоненты самостоятельно, используя репозиторий как справочный пример.
