# Blackgram — серверная версия

## Что уже есть
- Регистрация и вход по email/паролю (пароли хешируются bcrypt).
- Постоянное хранение пользователей, чатов и сообщений в SQLite.
- Переписка в реальном времени через Socket.IO между подключёнными устройствами.
- Создание чатов и групп.
- Админ-панель в меню кнопки ✎: статистика, список пользователей, блокировка/разблокировка.
- Мобильная вёрстка.

## Запуск на компьютере
Нужен Node.js 20 или новее.

```bash
npm install
```

Скопируй `.env.example` в `.env` и задай:
- `JWT_SECRET` — длинный случайный секрет.
- `ADMIN_EMAIL` — почта, которая получит роль администратора при регистрации.

Затем запусти:

```bash
npm start
```

Открой `http://localhost:3000`.

## Публикация в интернете
Размести папку проекта на Node.js-хостинге, который поддерживает постоянный процесс и WebSocket (например, Render или Railway). Укажи переменные окружения `JWT_SECRET` и `ADMIN_EMAIL`. Для SQLite нужен постоянный диск/volume, иначе база может сбрасываться при пересоздании контейнера. Для серьёзного публичного сервиса лучше заменить SQLite на PostgreSQL и добавить подтверждение email, сброс пароля, лимиты запросов, модерацию и резервные копии.

## Важно
Сейчас это рабочая стартовая версия, а не уже опубликованный сервис. Реальные сообщения между телефонами заработают после установки зависимостей и публикации сервера по HTTPS. Не используй стандартный JWT_SECRET в публичном интернете.
