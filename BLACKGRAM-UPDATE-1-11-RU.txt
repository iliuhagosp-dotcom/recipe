BLACKGRAM — ОБЪЕДИНЁННОЕ ОБНОВЛЕНИЕ 1–11
Версия проекта: 1.1.0

Включено в этот проект:
1. Новый адаптивный интерфейс на основе текущего Blackgram.
2. Админ-панель: просмотр пользователей и блокировка/разблокировка. Главный администратор определяется по ADMIN_EMAIL в index.html.
3. Обновление веб-версии через service worker; сборка APK автоматически запускается GitHub Actions при push в main/master.
4. Группы (сохранена существующая функция) и создание каналов.
5. Короткие голосовые сообщения (до 40 секунд; запись ограничена размером документа Firestore).
6. Blackgram AI не добавлен по просьбе владельца проекта.
7. Настройка скрытия профиля из каталога и ссылка на правила Firestore в пояснениях интерфейса.
8. Аудио- и видеозвонки через WebRTC и Firestore-сигнализацию (экспериментально; необходимы разрешения микрофона/камеры и правила Firestore для коллекции calls).
9. Реакции, сохраняемые в документе сообщения, и набор emoji-стикеров.
10. Четыре темы: ночная, светлая, лесная, фиолетовая.
11. Редактирование имени, статуса и HTTPS-ссылки на аватар.

Файлы index.html и www/index.html синхронизированы. capacitor.config.json использует www как webDir.

УСТАНОВКА
1. Скачайте ZIP и распакуйте его.
2. Загрузите содержимое папки recipe-main в корень GitHub-репозитория, заменив совпадающие файлы и добавив новые sw.js и manifest.webmanifest.
3. Сделайте Commit changes в ветку main.
4. Откройте GitHub → Actions → Build Blackgram APK. Дождитесь зелёного статуса.
5. Откройте завершённый запуск workflow и скачайте артефакт Blackgram-debug-apk.

ВАЖНО
- В этом архиве сохранён исходный Firebase-проект и его конфигурация.
- После обновления проверьте правила Firestore. Клиентский интерфейс не заменяет серверные правила безопасности.
- Для звонков Firestore должен разрешать авторизованным участникам читать/создавать/обновлять только относящиеся к ним документы calls и подколлекции кандидатов. Для надёжных звонков в сетях с NAT может понадобиться TURN-сервер; сейчас указан публичный STUN.
- Голосовые сообщения хранятся как небольшие data URL в Firestore. Для большого объёма аудио правильнее подключить Firebase Storage и ограничить доступ правилами.
- Автообновление service worker относится к веб-версии. APK собирается автоматически в GitHub Actions, но Android может потребовать установить новый APK; тихая установка APK без публикации и разрешений Android не выполняется.
- Звонки и Firebase-функции не могли быть проверены на реальных двух устройствах в этой среде. Перед использованием проверьте регистрацию, сообщения, запись голоса и звонки на двух аккаунтах.
