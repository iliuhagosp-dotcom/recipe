BLACKGRAM — СБОРКА APK С ТЕЛЕФОНА

В этой папке находится твоя текущая веб-версия Blackgram, обёртка Android на Capacitor и GitHub Actions workflow для автоматической сборки APK.

КАК СОБРАТЬ APK
1. Скачай ZIP и распакуй его на телефоне.
2. Открой свой репозиторий GitHub, где сейчас опубликован Blackgram.
3. Загрузи в корень репозитория ВСЕ файлы и папки из этой сборки, сохраняя структуру. Разреши заменить index.html и добавить package.json, capacitor.config.json, .gitignore и папку .github/workflows.
4. Нажми Commit changes.
5. В репозитории открой вкладку Actions.
6. Выбери Build Blackgram APK. Если сборка не стартовала автоматически, нажми Run workflow → Run workflow.
7. Дождись зелёной галочки у завершённой сборки.
8. Открой завершённый запуск workflow, внизу найди Artifacts и скачай Blackgram-debug-apk.
9. Распакуй скачанный архив и установи app-debug.apk. Android может попросить разрешить установку из этого источника.

ВАЖНО
- Это debug APK для установки и тестирования, не подписанный релиз для Google Play.
- Для переписки, регистрации и групп по-прежнему нужен интернет и настроенный Firebase-проект blackgram-35ecf.
- В Firebase Authentication должен быть включён Email/Password.
- Правила Firestore должны быть опубликованы отдельно в Firebase Console. APK не исправляет и не заменяет правила базы данных.
- В этой версии есть регистрация/вход, список пользователей, личные сообщения, группы, Избранное и простая админ-панель. Звонки, отправка фото/файлов, push-уведомления и каналы пока не реализованы.
- API-ключ Firebase, находящийся в HTML, является клиентским ключом Firebase. Безопасность обеспечивается корректными Firebase Security Rules и ограничениями проекта, а не сокрытием этого ключа.
- APK будет собираться на серверах GitHub Actions; на телефоне не нужен компьютер.
