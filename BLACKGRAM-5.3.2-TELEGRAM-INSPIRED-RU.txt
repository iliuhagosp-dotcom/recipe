BLACKGRAM 5.3.2 — ОБНОВЛЕНИЕ ЧАТОВ, ПЕРЕПИСКИ, ГОЛОСА И СТИКЕРОВ

В этой сборке добавлены Telegram-подобные сценарии, реализованные собственным кодом Blackgram поверх Firebase. Исходники Telegram Android не копировались напрямую.

1. СПИСОК ЧАТОВ
- Фильтры: Все, Личные, Группы, Каналы, Архив.
- Архивные чаты доступны отдельной вкладкой фильтра.
- Существующие закрепления, поиск и счётчики непрочитанных сохранены.

2. ПЕРЕПИСКА
- Добавлена пересылка текстового сообщения в другой чат.
- Сохраняются существующие ответы, редактирование, удаление и реакции.
- Пересланные сообщения получают отметку об отправителе исходного сообщения.

3. ГОЛОСОВЫЕ
- Сохранена запись голосовых сообщений с микрофона и отправка через текущий Firebase-путь.
- Для аудиосообщений добавлено переключение скорости воспроизведения: 0.5x, 1x, 1.5x, 2x.
- Лимит записи в текущей реализации — до 40 секунд; для крупных файлов используется существующая загрузка в Storage.

4. СТИКЕРЫ И РЕАКЦИИ
- Выбор стикера теперь отправляет его как отдельное sticker-сообщение, а не просто вставляет символ в поле ввода.
- Можно создавать свои emoji-стикеры; набор хранится локально на устройстве.
- Расширен быстрый набор реакций. Для реакции на конкретное сообщение удерживай сообщение.

ПРОВЕРКИ
- Выполнена проверка синтаксиса JavaScript через node --check.
- Это исходный пакет сайта/PWA Blackgram, а не готовый APK.
- Firebase не развёртывался из этой среды; для работы нужны опубликованный сайт и действующие Firebase Rules/настройки.

ПРИМЕЧАНИЕ
Изменения являются самостоятельной реализацией функций в проекте Blackgram, а не переносом исходного кода Telegram. Если в дальнейшем будут включаться фрагменты Telegram Android, необходимо отдельно соблюдать GPL и требования к публикации исходников.
