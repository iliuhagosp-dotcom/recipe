BLACKGRAM 5.3 — CREATOR CONTROL

На базе Blackgram 5.2. Существующий интерфейс и Control Center сохранены.

Добавлено:
- Вкладка «Активность» внутри Control Center, видимая только владельцу iliuhagosp@gmail.com.
- Журнал открытия чатов и отправки сообщений: участники, название/тип чата и время. Текст сообщений, фото, файлы и аудио не копируются в журнал.
- Сбор IP подключения через защищённую Firebase Callable Function. Клиент не может подставить IP самостоятельно.
- Явное согласие пользователя при первом входе; отказ не мешает пользоваться мессенджером. Согласие можно изменить в «Приватность».
- Правила Firestore: читать оба журнала может только владелец; клиентские записи IP запрещены.

ВАЖНО — ВКЛЮЧЕНИЕ IP-ЖУРНАЛА
1. В корне проекта установи Firebase CLI и выполни `firebase login`.
2. Выполни `firebase deploy --only functions:recordConnection,firestore:rules`.
3. Для Cloud Functions проекту может потребоваться подключённый тариф Blaze и включённый биллинг Google Cloud.
4. После деплоя загрузи обновлённые index.html, www/index.html и public/index.html в свой хостинг/репозиторий.

Без развёрнутой Cloud Function журнал активности чатов работает после согласия, а IP-записи не появятся. Геолокация по IP не добавлена: IP не гарантирует точное местоположение.
