# Blackgram 7.7 — профиль и фото

- Загрузка фото профиля из галереи: круглая обрезка (перетаскивание + масштаб), сжатие до 512x512 WebP, прогресс загрузки, путь avatars/{uid}/.
- Баннер профиля (обрезка 2:1, 1080 px).
- Галерея аватарок (до 6): свайп по аватарке в профиле, просмотр на весь экран, закрытие свайпом вниз. Лишние старые файлы и заменённый баннер удаляются из Storage.
- Кнопка-камера на своём профиле для быстрой смены фото.
- Пустое поле «Часы работы» больше не показывается; день рождения выбирается календарём.
- Вкладки «Медиа» и «Ссылки» берутся из общего личного чата (до 200 последних сообщений); фото с пометкой 18+ в сетку не попадают. «Музыка» показывает указанный трек. «Голосовые» и «Подарки» пока без данных.
- Приватность: кто видит фото, «в сети» и день рождения (все / только мои чаты / никто).
- functions/index.js: в publicProfiles добавлены banner, photos, privacy, about, birthday. Нужен деплой функций и один вызов backfillPublicProfiles.
- Приватность скрывает данные только в интерфейсе приложения, это не защита на уровне правил Firestore.
