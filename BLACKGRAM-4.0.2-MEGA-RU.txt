BLACKGRAM 4.0.2 — MEGA UPDATE

Что добавлено:
- Жалоба на пользователя прямо из личного чата.
- Выбор категории жалобы и поле подробностей.
- Отправка жалобы в Firestore, коллекция reports.
- Очередь жалоб в Blackgram Control Center.
- Статусы «На проверке» и «Закрыта» с фиксацией модератора и времени.
- Правила Firestore для создания жалоб пользователями и чтения/обработки только владельцем или модераторами с manageReports.
- Объявления показываются пользователям при следующем входе; обновлён текст подтверждения публикации.
- Режим обслуживания проверяется при авторизации: обычные пользователи не входят, владелец и администраторы сохраняют доступ.
- Обновлён кэш Service Worker до v402 во всех копиях приложения.
- Обновлены все три HTML-точки входа: index.html, public/index.html, www/index.html.

Установка:
1. Сделай резервную копию проекта и текущих Firestore Rules.
2. Загрузи файлы из архива в репозиторий.
3. Опубликуй firestore.rules в Firebase Console → Firestore Database → Rules.
4. Проверь жалобу тестовыми аккаунтами: отправитель создаёт жалобу, модератор с manageReports видит и закрывает её.
5. Перезапусти приложение/обнови страницу, чтобы загрузился новый Service Worker.

Проверка: JavaScript прошёл синтаксическую проверку Node.js; архив проверен unzip -t. Firebase-запросы и APK не выполнялись в этом окружении. Для APK используй GitHub Actions → Build Blackgram APK.
Blackgram AI не добавлялся.
