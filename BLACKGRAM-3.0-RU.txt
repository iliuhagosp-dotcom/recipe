BLACKGRAM 3.0 — RELEASE NOTES (RU)

Основа: исходный проект Blackgram 2.7.

Сохранено из 2.7:
- Регистрация и вход через Firebase Authentication.
- Личные сообщения, группы, каналы и «Избранное».
- Ответы, редактирование и удаление собственных сообщений.
- Реакции, стикеры, голосовые сообщения и отправка фотографий.
- Аудио- и видеозвонки через WebRTC (при корректной настройке сигнализации и доступе к устройству).
- Поиск, темы оформления, профили, приватность и административная панель.

Изменения 3.0 в этом пакете:
- Версия и заголовок приложения обновлены до 3.0.
- Добавлено локальное сохранение черновиков отдельно для каждого чата на текущем устройстве.
- При повторном открытии чата черновик восстанавливается; после отправки очищается.
- Добавлен Service Worker с версионированным кэшем оболочки и сетевым приоритетом для навигации.
- Синхронизированы web entrypoints index.html, www/index.html и public/index.html.

ВАЖНО:
- Это обновление фронтенда. Оно не разворачивает Firebase и не меняет Firestore/Storage Security Rules.
- Перед публикацией проверь Firebase config, правила Firestore и Storage, авторизацию домена и настройки GitHub Pages.
- Реальная работа звонков зависит от корректных ICE/STUN/TURN настроек и сигнализации.
- Service Worker обновится после публикации; старый кэш может обновиться не мгновенно.
- Проверяй проект сначала тестовыми аккаунтами, не используй реальные секреты в публичном репозитории.
